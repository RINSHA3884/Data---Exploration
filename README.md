# Data Exploration

## Overview

This assignment focuses on **data exploration and analysis using Microsoft Excel**. It demonstrates the use of various Excel functions to analyze, manipulate, and extract information from a dataset.

The assignment includes functions such as **AVERAGE, COUNT, MIN, MAX, LEFT, RIGHT, MID, AND, . These functions are used to perform calculations, count and summarize data, extract specific characters from text, and apply logical conditions.

The assignment also includes basic **data manipulation and spreadsheet techniques**, helping to develop practical skills in organizing, analyzing, and interpreting data using Excel.

### Files Included

* **Excel file** – Contains the data exploration tasks and Excel functions used in the assignment.
* **Word file** – Contains the formulas used for corressponding questions.

This project demonstrates my understanding of **Excel functions, data exploration, data manipulation, and basic data analysis techniques**.
